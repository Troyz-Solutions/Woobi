# Woobi

Woobi is a Troyz Solutions application project developed collaboratively with internship contributors.

## Contribution workflow

- Interns should work in a fork or feature branch, never directly on `main`.
- Name branches `feature/WD-123-short-description` or `fix/WD-123-short-description`.
- Open a pull request against `main` and link the assigned Work Deck task.
- An authorized Troyz Solutions admin reviews and merges accepted changes.
- Do not commit passwords, API keys, tokens, `.env` files, or personal data.

See `CONTRIBUTING.md` and the pull request template once the collaboration setup PR is merged.
